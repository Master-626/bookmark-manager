# Bookmark Manager

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Productivity Tool](https://img.shields.io/badge/productivity-tool-green.svg)]()

A bookmark management CLI with import/export and link checking.

## ✨ Features

- **Add Bookmarks** - Save URLs with title, description, tags
- **Organize** - Folders/categories for organization
- **Search** - Find bookmarks by keyword, tag, URL
- **Import/Export** - Chrome/Firefox HTML format
- **Link Checking** - Verify bookmarks are still alive
- **Duplicate Detection** - Avoid duplicate bookmarks
- **Rich UI** - Beautiful colored terminal output

## 📦 Installation

```bash
git clone https://github.com/Master-626/bookmark-manager.git
cd bookmark-manager
pip install .
```

## 🚀 Quick Start

```bash
# Add a bookmark
bookmark-manager add https://github.com -t "GitHub" -g dev

# List bookmarks
bookmark-manager list

# Search bookmarks
bookmark-manager search github
```
